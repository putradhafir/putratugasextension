1. Builder Pattern

Builder Pattern adalah design pattern creational yang memungkinkan pembuatan objek kompleks secara bertahap. Pattern ini memisahkan proses konstruksi dari representasi akhir objek, sehingga proses pembuatan yang sama bisa menghasilkan representasi objek yang berbeda.

// ==========================================
// Nama  : Putra Dhafir Nashrullah
// NIM   : 251410009
// Kelas : SI2A
// ==========================================

class Config {}

class ConfigBuilder {
  ConfigBuilder host(String h) {
    print("Host : $h");
    return this;
  }
  ConfigBuilder port(int p) {
    print("Port : $p");
    return this;
  }
  Config build() {
    print("Config berhasil dibuat");
    return Config();
  }
}

void main() {
  ConfigBuilder()
      .host('localhost')
      .port(8080)
      .build();
}

2. Masalah Tanpa Extension Methods

Extension Methods adalah fitur yang memungkinkan kita menambahkan fungsi baru ke tipe data yang sudah ada, tanpa mengubah kode asli.

// ==========================================
// Nama  : Putra Dhafir Nashrullah
// NIM   : 251410009
// Kelas : SI2A
// ==========================================

class StringUtils {
  static String capitalize(String text) {
    if (text.isEmpty) return text;
    return text[0].toUpperCase() + text.substring(1);
  }
  static bool isEmail(String text) {
    return text.contains('@');
  }
}

void main() {
  var name = 'john';
  var capitalized = StringUtils.capitalize(name);
  var isEmail = StringUtils.isEmail('test@mail.com');
  print('Original name : $name');
  print('Capitalized    : $capitalized');
  print('Is Email       : $isEmail');
}

3. Solusi dengan Extension Methods

Extension Methods memberi kita kemampuan menambahkan method baru ke tipe data existing secara elegan dan readable.

// ==========================================
// Nama  : Putra Dhafir Nashrullah
// NIM   : 251410009
// Kelas : SI2A
// ==========================================

extension StringExtensions on String {
  String capitalize() {
    if (isEmpty) return this;
    return this[0].toUpperCase() + substring(1);
  }
  bool get isEmail => contains('@');
  String reverse() => split('').reversed.join();
}

void main() {
  var name = 'john';
  print('Capitalized    : ${name.capitalize()}');
  print('Is Email       : ${'test@mail.com'.isEmail}');
  print('Reverse hello  : ${'hello'.reverse()}');
}

4. Sintaks Extension Methods

Extension methods memungkinkan Anda menambahkan fungsi, getter, dan operator ke tipe data yang sudah ada.

extension DateTimeExtensions on DateTime {
  String toFormattedString() => '$day/$month/$year';
  bool get isToday {
    var now = DateTime.now();
    return year == now.year && month == now.month && day == now.day;
  }
  DateTime operator +(Duration duration) => add(duration);
}

5. Extension untuk Null Safety

Null Safety Extension membantu menangani nullable types dengan aman tanpa banyak pengecekan manual.

extension NullableStringExtensions on String? {
  String orEmpty() => this ?? '';
  bool get isNullOrEmpty => this == null || this!.isEmpty;
  bool get isNotNullOrEmpty => !isNullOrEmpty;
  String withDefault(String defaultValue) => this ?? defaultValue;
}

6. Utilities untuk Dart Types (PRAKTEK 1)

Membuat extension sebagai utilities untuk tipe data bawaan agar lebih bersih dan reusable.

extension NumberExtensions on num {
  String toRupiah() => 'Rp${toStringAsFixed(0)}';
  bool isBetween(num min, num max) => this >= min && this <= max;
  num power(int exponent) {
    var result = this;
    for (var i = 1; i < exponent; i++) result *= this;
    return result;
  }
}

7. Generic Extensions

Generic Extensions memungkinkan kita membuat extension method yang bekerja pada berbagai tipe data sekaligus.

extension ListExtensions on List {
  T? getOrNull(int index) => (index < 0 || index >= length) ? null : this[index];
  List> chunk(int size) {
    List> chunks = [];
    for (var i = 0; i < length; i += size) {
      chunks.add(sublist(i, i + size > length ? length : i + size));
    }
    return chunks;
  }
  List distinct() => [...{...this}];
}

8. Unnamed Extensions (Tanpa Nama)

Unnamed Extensions hanya terlihat di file yang sama, cocok untuk helper lokal tanpa konflik global.

extension on DateTime {
  String get toYYYYMMDD => '$year-${month.toString().padLeft(2, '0')}-${day.toString().padLeft(2, '0')}';
  DateTime get startOfDay => DateTime(year, month, day);
}

9. Konflik Nama Extension

Konflik terjadi saat dua extension memiliki method dengan nama sama pada tipe yang sama — solusi: panggil ekstensi secara eksplisit.

extension StringCaseExtensions on String {
  String capitalize() => "${this[0].toUpperCase()}${substring(1)}";
}
extension TextUtilsExtensions on String {
  String capitalize() => ">>> ${toUpperCase()} <<<";
}
void main() {
  var text = 'hello';
  print(StringCaseExtensions(text).capitalize());
  print(TextUtilsExtensions(text).capitalize());
}

10. Extension untuk Custom Classes

Extension bisa menambah fungsionalitas ke class buatan sendiri tanpa mengubah source asli, sangat powerful untuk codebase bersih.

class Product {
  final String name; final double price;
  Product(this.name, this.price);
}
extension ProductExtensions on Product {
  Product withDiscount(double percentage) => Product(name, price * (1 - percentage / 100));
  String get displayInfo => '$name - Rp${price.toInt()}';
  bool get isExpensive => price > 100000;
}

11. Validator Extensions (PRAKTEK 2)

Validator extensions membuat validasi data menjadi ekspresif, reusable, dan terorganisir.

extension StringValidators on String {
  bool get isEmail => RegExp(r'^[\w\.-]+@([\w-]+\.)+[\w-]{2,4}$').hasMatch(this);
  bool get isPhoneNumber => RegExp(r'^[0-9]{10,13}$').hasMatch(this);
  bool get isStrongPassword => length >= 8 && contains(RegExp(r'[A-Z]')) && contains(RegExp(r'[a-z]')) && contains(RegExp(r'[0-9]'));
}

12. Konflik Nama Antar Extension (BONUS)

Cara terbaik mengatasi konflik adalah dengan memanggil extension secara eksplisit atau menggunakan hide/show saat import.

extension StringNumber on String { int toInt() => int.parse(this); }
extension StringDouble on String { double toDouble() => double.parse(this); }
void main() {
  String angka = '123';
  print(StringNumber(angka).toInt());
  print(StringDouble(angka).toDouble());
}

13. Prioritas Method Asli vs Extension (Nullable)

Prioritas: Method asli class > Extension non-nullable > Extension nullable. Tipe variabel menentukan ekstensi mana yang digunakan.

class Greeting { String say() => 'Hello from class'; }
extension GreetingExt on Greeting { String sayExt() => 'Hello from extension'; }
void main() {
  Greeting? obj = Greeting();
  print(obj?.say());    // method asli
  print(obj?.sayExt()); // extension
}

✦ KESIMPULAN AKHIR

📌 Method vs Extension: Inti Perbedaan
Method adalah perilaku bawaan asli yang dirancang dari dalam suatu objek dan memiliki akses penuh ke seluruh datanya.

Extension adalah cara instan untuk menambahkan fungsi baru ke objek tersebut dari luar, tanpa harus membongkar atau mengubah kode aslinya.
🎯 Analogi Sederhana
Method adalah fitur bawaan pabrik — sudah melekat sejak awal.
Extension adalah aksesoris tambahan yang dipasang kemudian untuk memperluas fungsinya tanpa mengubah produk inti.
⚙️ Keunggulan Extension
• Tidak mengganggu kode asli — aman untuk library/package.
• Meningkatkan readability — kode jadi lebih ekspresif.
• Dapat digunakan pada tipe nullable maupun generik — fleksibel.
• Mencegah konflik — bisa dibuat lokal (unnamed) atau dipanggil eksplisit.
📐 Aturan Prioritas (PENTING)
1️⃣ Method Asli Class → selalu menang.
2️⃣ Extension Non-Nullable → dipanggil jika tipe variabel non-nullable.
3️⃣ Extension Nullable → dipanggil jika tipe variabel nullable (meski isinya tidak null).
💡 Gunakan panggilan eksplisit (NamaExtension(obj).method()) untuk menghindari ambiguitas.

✦ PENUTUP

Perbedaan mendasar antara Methods dan Extensions terletak pada asal dan hak aksesnya: Methods adalah fungsi internal bawaan objek, sedangkan Extension adalah fitur eksternal penambah kemampuan.
🧩 Kombinasi yang tepat dalam penggunaan keduanya akan sangat membantu programmer dalam menulis kode yang lebih rapi, efektif, dan mudah dipelihara. Extension methods membuka jalan menuju kode yang lebih deklaratif, reusable dan sesuai dengan prinsip Open/Closed.
